## Overview

This project applies supervised machine learning to predict the severity of road traffic
collisions in Great Britain. Each collision is classified into one of three categories:
**Fatal**, **Serious**, or **Slight**.

The input data consists of 503,475 police-reported collision records covering five years
(2019–2023), published by the UK Department for Transport under the Open Government
Licence v3.0. Three classifiers are trained and compared — Decision Tree, Random Forest,
and Gradient Boosting — with SMOTE oversampling applied to address severe class imbalance.
The best model (Gradient Boosting) achieves a test accuracy of 65.3% and a Macro F1
score of 0.364.

## How to Run

### Prerequisites

Install the required Python libraries:

```bash
pip install pandas numpy matplotlib scikit-learn imbalanced-learn
```

### Steps

1. Download the raw dataset from the link above and place it in `data/raw/`.
2. Run the main script:

```bash
python src/road_accident_severity.py
```

3. Processed data splits will be saved to `data/processed/`.
4. Output charts will be saved to `outputs/`.

---

## Pipeline Summary

1. **Load** — Raw CSV is loaded and relevant columns are selected.
2. **Clean** — Invalid values (−1) are treated as missing and removed, leaving 250,118 clean records.
3. **Explore** — Feature distribution charts are generated and saved.
4. **Split** — Data is split into training (70%), validation (15%), and test (15%) sets using stratified sampling.
5. **Resample** — SMOTE is applied to the training set only to address class imbalance (Fatal: 0.9%).
6. **Train** — Three models are trained: Decision Tree, Random Forest, Gradient Boosting.
7. **Select** — The best model is selected based on Macro F1 score on the validation set.
8. **Evaluate** — The best model is evaluated on the test set.
9. **Output** — Confusion matrix, performance comparison, and feature importance charts are saved.
